# 📊 Data Cleaning & Reporting Automation

An automated data cleaning and reporting dashboard built using Python, Pandas, and Streamlit.

## 📌 Project Overview

This project automates common data preprocessing and reporting tasks. Users can upload CSV or Excel files, clean the data, analyze it, and generate visual reports.

## 🚀 Features

- Upload CSV and Excel files
- Detect missing values
- Remove duplicate records
- Handle missing numeric values
- Standardize text and city names
- Calculate total sales
- Generate automatic KPIs
- Generate sales charts
- Download cleaned CSV files
- Download cleaned Excel reports

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- OpenPyXL

▶️ How to Run the Project
Step 1: Clone the repository
git clone YOUR_GITHUB_REPOSITORY_LINK
Step 2: Open the project folder
cd Data-Cleaning-Reporting-Automation
Step 3: Install the required libraries
pip install -r requirements.txt
Step 4: Run the application
python -m streamlit run app.py
Step 5: Open the dashboard

The terminal will display a local address such as:

http://localhost:8501

Open that address in your web browser.
